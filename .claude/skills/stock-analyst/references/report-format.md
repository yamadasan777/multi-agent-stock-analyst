# Report Format — Quick Reference

> Note: Full template is now inlined in SKILL.md. This file is kept for reference only.

## Chat Output (under 400 words)
- Current price, recommendation, target
- Executive summary table (agents x verdict x confidence)
- Bullish/bearish signs (2+ agents agree)
- 3-step action plan

## File Report (reports/YYYYMMDD/{ID}.md)
- Executive summary (same as chat)
- Agent summaries (200-300 words each, NOT verbatim paste)
- Integrated insights
- Risk/reward with price levels
- Action plan
- Disclaimer

## Key Rules
- Be decisive — clear recommendation, not "it depends"
- Confidence: HIGH = agents agree, MEDIUM = mixed, LOW = disagreement
- Action plan: concrete, specific, actionable
- All user-facing text in Japanese
